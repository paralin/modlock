A [Luau](https://luau.org) mod requires `@modlock` and registers its handlers
in `main.luau`:

```luau
local modlock = require("@modlock")

modlock.command("hello", function(player)
	player:chat("Hello from Luau!")
end)
```

The library's types check in strict mode. An editor with the Luau language
server finds the library and completes its calls. One module requires another by
its relative path, such as `require("./round")`, as the
[`bounty`](https://github.com/paralin/modlock/tree/master/examples/bounty)
example does.

The Luau library mirrors the TypeScript API using method syntax, such as
`player:chat(text)`. Because Luau numbers cannot represent every 64-bit
integer, 64-bit IDs (such as Steam IDs) are passed as decimal strings.

A `Player` reference remains the same object for as long as one person holds
that slot, so `==` compares player identity and `Player` values work as table
keys. If a new player takes the slot later, they receive a distinct object and
do not inherit table entries from the previous player.

Build interfaces with `@modlock/ui`, `@modlock/hud` and `@modlock/theme`. Choose
Luau with the switch in the sidebar, and the [guides](/guides/events) show every
call in Luau.

## Typed entities

`@modlock/entities` reads and writes entity fields and creates entities. Give
each entity a type, so the analyzer checks the fields and inputs you use:

```luau
local entities = require("@modlock/entities")

local hero: entities.CCitadelPlayerPawn = entities.new("CCitadelPlayerPawn", pawn.entity)
hero.m_iHealth = (hero.m_iHealth or 0) + 50

local keys: entities.CNPC_TrooperBossKeys = { LaneNum = 2 }
local boss: entities.CNPC_TrooperBoss? = entities.create("npc_trooper_boss", { position = position, keys = keys })
```

## The console

With `@modlock/console` you set console variables with `setBoolean`,
`setNumber` and `setString`, and run console commands with `run`:

```luau
local console = require("@modlock/console")

console.setBoolean("citadel_allow_purchasing_anywhere", true)
console.run("changelevel", "street_test")
```
