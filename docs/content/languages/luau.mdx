A [Luau](https://luau.org) mod requires `@modlock` and registers its handlers
in `main.luau`:

```luau
local modlock = require("@modlock")

modlock.command("hello", function(player)
	player:chat("Hello from Luau!")
end)
```

The types check in strict mode, and editors with the Luau language server
resolve the library too. A module requires another by its relative path, such
as `require("./round")`, as the [`bounty`](https://github.com/paralin/modlock/tree/master/examples/bounty) example does.

The library offers the calls of the TypeScript one under the same names, with
methods called as `player:chat(text)`. A 64-bit id, such as a Steam ID, is a
decimal string. Interfaces are built with `modlock/ui`,
`modlock/hud` and `modlock/theme`.

This page covers what is particular to the language. The
[guides](/guides/events) show every call in it: choose it with the switch
in the sidebar.

## Damage and input

```luau
-- Shrug off half of every hit on the holder.
modlock.onDamage(function(hit)
	local pawn = holder:pawn()
	if pawn and hit.victim == pawn.entity then
		return { amount = hit.amount * 0.5 }
	end
	return nil
end)

-- Answer the attack button.
modlock.onInput(function(player, pressed)
	if modlock.has(pressed, modlock.Buttons.attack) then
		player:centerText("Fire!")
	end
end)
```

## Typed entities

`@modlock/entities` reads and writes fields and creates entities. Name each
entity's type so the analyzer checks it:

```luau
local entities = require("@modlock/entities")

local hero: entities.CCitadelPlayerPawn = entities.new("CCitadelPlayerPawn", pawn.entity)
hero.m_iHealth = (hero.m_iHealth or 0) + 50

local keys: entities.CNPC_TrooperBossKeys = { LaneNum = 2 }
local boss: entities.CNPC_TrooperBoss? = entities.create("npc_trooper_boss", { position = position, keys = keys })
```

## The console

`@modlock/console` sets variables with `setBoolean`, `setNumber` and
`setString`; `run` runs a command:

```luau
local console = require("@modlock/console")

console.setBoolean("citadel_allow_purchasing_anywhere", true)
console.run("changelevel", "street_test")
```
