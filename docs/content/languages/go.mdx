A Go mod is a `main` package that imports
[`github.com/paralin/modlock/mod`](https://github.com/paralin/modlock/tree/master/mod) and registers its handlers in `init`:

```go
package main

import "github.com/paralin/modlock/mod"

func init() {
	mod.Command("hello", func(p mod.Player, args string) {
		_ = p.Chat("Hello from Go!")
	})
}

func main() {}
```

This page covers what is particular to the language. The
[guides](/guides/events) show every call in it: choose it with the switch
in the sidebar.

## Errors and tests

Each call into the game returns an error, which a mod may ignore to keep
playing. Game rules that make no calls, such as those in the
[`race`](https://github.com/paralin/modlock/tree/master/examples/race) example, test with plain `go test`. Interfaces
are built from the `mod/ui`, `mod/hud` and `mod/theme` packages.

## Damage

Handlers see every hit before the game applies it, and can change or block it:

```go
// Headshots deal double damage.
mod.OnDamage(func(hit *mod.DamageEvent) *mod.DamageResult {
	if hit.GetHitGroup() != 1 {
		return nil
	}
	amount := hit.GetAmount() * 2
	return &mod.DamageResult{Amount: &amount}
})
```

## Typed entities and the console

[`mod/entity`](https://github.com/paralin/modlock/tree/master/mod/entity) types every entity field and input, and
[`mod/console`](https://github.com/paralin/modlock/tree/master/mod/console) every console variable and command:

```go
// Set a hero's health.
hero := entity.CBaseEntity(entity.CCitadelPlayerPawn{Handle: pawn.GetEntity()})
_ = hero.IHealth().Set(500)

// Raise the trooper bounty and change the map.
_ = console.CitadelTrooperGoldReward.Set(40)
_ = console.Changelevel.Run("street_test")
```
