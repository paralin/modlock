A TypeScript or JavaScript mod imports `modlock` and registers its handlers
when it loads:

```ts
import { command } from 'modlock'

command('hello', (player) => {
  player.chat('Hello from TypeScript!')
})
```

The [guides](/guides/events) show every call in TypeScript and JavaScript;
choose the language with the switch in the sidebar. [Camera
curves](/guides/camera) and `ProbeRun` for [testing](/guides/testing) are in
TypeScript only.

## The build

`main.ts`, or `main.js`, is the entry, and a JavaScript mod is checked from its
JSDoc. Nothing else needs installing: each build writes the library's types to
`node_modules/modlock` for editors and the type checker, and bundles the mod
with the library built into `modlock`.
[`src/wasm/wasm.proto`](https://github.com/paralin/modlock/blob/master/src/wasm/wasm.proto)
documents every call, its arguments and its result.

## Two runtimes

Every build bundles the mod for QuickJS, which runs any JavaScript and builds in
a moment. A mod whose frames run too long can set `"runtime": "RUNTIME_WASM"`
in its `mod.json`. `modlock publish` then compiles it ahead of time to
WebAssembly with [scriptc](https://scriptc.dev), downloaded the first time,
which runs about 2.5 times faster but takes about a minute and a few gigabytes
of memory to build. `modlock build --release` builds the same way, to check
before you publish.

The build ships the QuickJS bundle instead, and `modlock publish` refuses it
unless you pass `--allow-fallback`, in two cases:

- scriptc cannot compile part of the mod. The build lists each place and why.
- The two builds behave differently. The build plays both in the sandbox, a
  start, a player, the world and five seconds of frames with one clock and the
  same random bytes. Each event goes to QuickJS first, and WebAssembly gets
  QuickJS's reply to each equal call. The build prints the first event where
  their calls or answers differ, with what each did there. A run of server commands compares as a set, since their order does
  not change the game. The check builds QuickJS with scriptc's zig, once per
  version.
