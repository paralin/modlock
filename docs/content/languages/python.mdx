A Python mod imports `modlock` and registers its handlers with decorators in
`main.py`:

```python
import modlock


@modlock.command("hello")
def hello(player: modlock.Player, args: str) -> None:
    player.chat("Hello from Python!")
```

This page covers what is particular to the language. The
[guides](/guides/events) show every call in it: choose it with the switch
in the sidebar.

## Types and modules

Pyright and Pylance check the types. A wrong type is an error that stops the
build. A value that may be `None`, such as what `find_hero` returns, and a
parameter without an annotation are warnings: the build prints them and goes
on. For stricter or looser checking, edit `typeCheckingMode` and the report
rules in the project's `pyrightconfig.json`. The checkers read that file,
which also points them at the library in `.modlock`, only from the folder the
editor has open: open the mod's own folder, or the editor reports that
`modlock` could not be resolved. A module imports another by
name, such as `import round`. Mods run on Python 3.14 with standard modules such
as `dataclasses`, `enum`, `json`, `math`, `random` and `re`.

## The library

The library has the TypeScript calls in snake_case. Messages are dataclasses,
enums are string literals, and 64-bit ids are Python integers. Interfaces are
built with `modlock.ui`, `modlock.hud` and `modlock.theme`.

```python
# Headshots deal double damage.
@modlock.on_damage
def headshots(hit: modlock.DamageEvent) -> modlock.DamageResult | None:
    if hit.hit_group == 1:
        return modlock.DamageResult(amount=hit.amount * 2)
    return None


# Pay a soul bonus on /bonus.
@modlock.command("bonus")
def bonus(player: modlock.Player, args: str) -> None:
    player.adjust_souls(500)
    player.announce("Bonus", "500 souls")


# Answer the attack button.
@modlock.on_input
def fire(
    player: modlock.Player, pressed: modlock.Buttons, released: modlock.Buttons
) -> None:
    if pressed & modlock.Buttons.ATTACK:
        player.center_text("Fire!")
```

## Typed entities and the console

`modlock.entities` types each entity class, with its fields as attributes, and
creates entities by designer name. `modlock.console` sets console variables by
name and runs commands. Import each beside `modlock`:

```python
from modlock import console, entities

# Set a hero's health.
hero = entities.CCitadelPlayerPawn(pawn.entity)
hero.m_iHealth = 500

keys: entities.CNPC_TrooperBossKeys = {"LaneNum": 2}
boss = entities.create("npc_trooper_boss", modlock.Vector(x=0, y=0, z=0), keys=keys)

console.set_number("citadel_trooper_gold_reward", 40)
console.run("changelevel", "street_test")
```

A field reads as `None`, and a write is ignored, when the server cannot read
or write it; the server log says why.
