---
title: Playing together
description: Play a mod you are building with friends on their own PCs.
---

On your PC, open a friends lobby:

```sh
modlock play --lobby
```

On each other PC, join it with the link the lobby shows:

```sh
modlock join LINK
```

`join` launches Deadlock and joins the server once the player is in the lobby.
Each guest downloads the mod's content from the host before joining. Content
changed after that loads when the guest joins again.

Both PCs sign in first with `modlock login`, which `modlock publish` also
saves. Only a creator who may publish mods can open a lobby, and only the
creator's friends can join it. The PCs link directly over WebRTC, through
Hyperline's relay while the lobby is open when routers block a direct link.

## Join codes

`modlock play --host` gives a join code instead of a lobby; the other PC runs
`modlock join CODE`. Anyone holding the code can join until the host stops.
The code needs a direct connection between the PCs. When a lobby cannot open,
`--lobby` falls back to a join code and says why. In the sandbox, play goes on locally without hosting.

## Which mods play

A source project rebuilds and reloads on each save, and only one can be
watched. Built mods run directly, several at once. To play several source
projects, pass `--watch=false`, which uses each one's existing build and builds
it first if it has none.
