---
title: Publishing
description: Release a mod for others to play.
---

`modlock publish` builds the mod and runs the check each host runs: the module
may import only Modlock and WASI functions, and must start and answer its first
event within the limits. It then goes where `--to` says:

| `--to`      | Effect                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------ |
| `hyperline` | The default. Upload the mod to [hyperline.gg](https://hyperline.gg).                             |
| `archive`   | Write `SLUG-VERSION.zip` to `--out`: the mod, `modlock.exe` and `Play.cmd` to run it on Windows. |
| `github`    | Attach that zip to the GitHub release `SLUG-vVERSION`, creating the release if needed.           |

`modlock login` opens the browser to sign in to hyperline.gg and saves the
session for every later command, and `modlock logout` removes it; the first
upload signs in the same way when no session is saved. Publishing there needs access during the alpha; ask for it in the
[Hyperline Discord](https://discord.gg/DCErWrCFvh). `--origin` points it at
another service with the same API. The `github` destination uses the
[`gh`](https://cli.github.com) command line and its sign-in.

The built `mod.json` keeps every field of yours that Modlock does not read,
such as a store's description, so the destination reads them.

Hyperline publishes each version once, so raise `version` in `mod.json` before
publishing again. `--notes` says what changed: hyperline.gg shows it on the
game's page, and the `github` destination uses it for a new release.

`--prerelease` publishes to hyperline.gg for the mod's testers only, with a
version such as `0.2.0-pre.1`. Every game keeps its release. Each of the mod's
games gains a Draft copy, such as "Zombie Tag Prerelease", that plays the
prerelease, and anyone a tester invites may join it. A later prerelease
replaces it. Choosing it current on hyperline.gg (`hyperline-mod current SLUG
VERSION`) makes that same build the release, without publishing again.

After the upload, `modlock publish` says where the release plays. A mod with
code plays on hyperline.gg's game servers at once, and on players' own PCs once
a reviewer approves it, unless the creator is trusted, whose releases play
everywhere when published.

A mod that ships its own layouts, models or sounds publishes them with it;
see [client content](/guides/client-content).
