## Vectors and HUD text

`vector` works in world units with z up and view angles in degrees, pitch
positive looking down. `vector.distance`, `flatDistance`, `toward`, `lerp`
and the arithmetic helpers place things; `yawToward`, `level`, `aimAt` and
`forward` turn a hero to face a point or read where it looks.

`format` writes the numbers a HUD shows the way players read them, since the
game's scripts have no locale data: `clock(65)` is `1:05`, `stopwatch(64.37)`
is `1:04.37`, `percent(3, 4)` is `75%`, `grouped(4210)` is `4,210`,
`ordinal(2)` is `2nd`, `count(3, 'kill')` is `3 kills` and
`clip('Lady Geist wins', 10)` is `Lady…`.

## Seat the players

`seatPlayers` gives every player who joins a hero on a team, with no team or
hero screen, and keeps them seated: it brings a fallen hero back after the
respawn delay and seats a player again after a hero change. One line does it:

<Samples>

```ts
import { seatPlayers } from 'modlock'

seatPlayers({ hero: 'any', respawn: 3 })
```

```luau
modlock.seatPlayers({ hero = "any", respawn = 3 })
```

```python
modlock.seat_players(hero="any", respawn=3)
```

```go
mod.SeatPlayers(mod.Seating{Hero: mod.AnyHero, Respawn: 3 * time.Second})
```

</Samples>

The hero is a hero's name, as players know it or as the game does, its id, or
any: the hero the player has, or else a
random one. Without a team each player joins the side with fewer heroes. Give
a team, 2 or 3, to put everyone on it, or a function that picks the team for
each player as they join:

<Samples>

```ts
seatPlayers({
  hero: 'haze',
  team: ({ player }) => (player.slot % 2 === 0 ? 2 : 3),
})
```

```luau
modlock.seatPlayers({
	hero = "haze",
	team = function(connection)
		return if connection.player.slot % 2 == 0 then 2 else 3
	end,
})
```

```python
def team_for(connection: modlock.Connection) -> int:
    return 2 if connection.player.slot % 2 == 0 else 3


modlock.seat_players(hero="haze", team=team_for)
```

```go
mod.SeatPlayers(mod.Seating{
	Hero: "haze",
	TeamOf: func(connection *mod.Connection) int32 {
		return 2 + connection.GetPlayer()%2
	},
})
```

</Samples>

`seatPlayers` is a [`Cast`](#keep-the-players-with-cast) that runs itself, and
returns it. Use a Cast directly when the mod keeps its own state for each
player or changes what a player wants during the game.

## Keep the players with Cast

`Cast` keeps one member per human who finished joining. It calls your `join`
when someone arrives and `leave` when they go, and treats a reconnect as a
leave and a join, so a member never carries the last player's state. It learns
of joins from the host's player reports, so a frame where nobody came or went
walks no player list. Bots are left out unless the `bots` option says to make
them members or kick them.

A member can want a hero, a team and a respawn delay. Each frame, Cast reads
each member's hero once and asks the game, at most once a second, for whatever
the hero does not show yet, until it does. Give one want for everyone, or a
function of the member that Cast reads each frame. Without a team, a member
keeps their hero's team or joins the side with fewer members. Read the hero
back from the cast instead of asking the game again.

This cast welcomes each player, seats them on any hero and brings a fallen
hero back after 3 seconds:

<Samples>

```ts
import { Cast, onFrame } from 'modlock'

const cast = new Cast({
  join: ({ player, name }) => {
    player.announce('My Mod', `Welcome, ${name}.`)
    return { player, kills: 0 }
  },
  want: { hero: 'any', respawn: 3 },
})

onFrame(({ timeSeconds }) => cast.frame(timeSeconds))
```

```luau
local cast = modlock.Cast.new({
	join = function(connection: modlock.Connection)
		connection.player:announce("My Mod", "Welcome, " .. connection.name .. ".")
		return { player = connection.player, name = connection.name, kills = 0 }
	end,
	want = { hero = "any", respawn = 3 },
})

modlock.onFrame(function(frame)
	cast:frame(frame.timeSeconds)
end)
```

```python
def welcome(connection: modlock.Connection) -> modlock.Player:
    connection.player.announce("My Mod", f"Welcome, {connection.name}.")
    return connection.player


cast = modlock.Cast(welcome, want=modlock.Want(hero="any", respawn=3))


@modlock.on_frame
def frame(event: modlock.FrameEvent) -> None:
    cast.frame(event.time_seconds)
```

```go
// import "time"
cast := mod.NewCast(mod.CastOptions[mod.Player]{
	Join: func(connection *mod.Connection) mod.Player {
		player := mod.Player{Slot: connection.GetPlayer()}
		_ = player.Announce("My Mod", "Welcome, "+connection.GetName()+".")
		return player
	},
	Want: mod.Want{Hero: mod.AnyHero, Respawn: 3 * time.Second},
})

mod.OnFrame(func(frame *mod.FrameEvent) { cast.Frame(frame.GetTimeSeconds()) })
```

</Samples>

The cast answers who is here and where their hero is:

| TypeScript and Luau | Python      | Go        | Returns                                   |
| ------------------- | ----------- | --------- | ----------------------------------------- |
| `size`              | `size`      | `Size`    | How many members there are.               |
| `members`           | `members()` | `Members` | Every member.                             |
| `get(player)`       | `get`       | `Get`     | The member for a player, if they are one. |
| `pawn(player)`      | `pawn`      | `Pawn`    | The member's hero as Cast last read it.   |

## Find the floor

`ground(point)` returns the floor under a point with one trace straight down,
from 64 units above it to 1024 below, through solid and player clip. It
returns nothing when no floor is in reach, when the point is inside a wall, or
before the world's collision is ready, so `ground(spawn) ?? spawn` keeps the
point when there is no floor. `above`, `below` and `layers` change the reach.

## Stand a race gate

`RaceGate.stand` stands a checkpoint or finish gate across a lane. The gate is
a window of thin glowing lines inside a racing checker band that runs round
its sides and top. It is Tron cyan by default, and a runner reads it at once
as "go through here". `foot` is the road point under the middle of the
opening, and `yaw` is the direction a runner passes through, in degrees.
Precache `raceGateResources` in `onStart`:

```ts
import { ground, onStart, precache, RaceGate, raceGateResources } from 'modlock'

onStart(() => precache({ resources: raceGateResources }))

const gate = RaceGate.stand({ foot: ground(spot) ?? spot, yaw: 90 })
gate.remove()
```

`width` and `height` size the opening, 112 by 144 units by default, rounded to
whole 8-unit cells. `color` and `faded` color the band's inner and outer
rings, and `viewer` shows the gate to one player slot only. World text and
beams ignore alpha, so the outer ring uses a darker shade to look see-through.

## Time your frames

`frameClock` shows how much of a slow server's frame is your mod's, and which
part spends it. Call `begin` as a frame starts, `lap` with a name after each
part, and `end` with the frame's tick. Once a minute it logs the median and
slowest frame, each part's mean and slowest milliseconds, and the parts that
cost the most in the minute's slowest frame, which a part that spikes once a
minute needs to show up at all.

```ts
import { frameClock, onFrame } from 'modlock'

onFrame((frame) => {
  frameClock.begin()
  moveBots()
  frameClock.lap('bots')
  drawHud()
  frameClock.lap('hud')
  frameClock.end(frame.tick)
})
```
