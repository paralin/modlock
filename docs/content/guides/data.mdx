---
title: Settings, metrics and boards
description: Let players choose, count what they do and rank them.
---

A mod declares three kinds of data in its manifest, and the host keeps them
for it: settings a player chooses, metrics that count what players do, and
boards that rank them. Nothing here needs a database of your own.

## Settings

Declare a setting in [`mod.json`](/reference/manifest#settings), then read
it. Every value is text, and bots read the defaults.

<Samples>

```ts
import { settingNumber, settingOn } from 'modlock'

const layout = player.setting('layout') // 'full' or 'compact'
const sounds = settingOn(player, 'sounds') // a switch, as a boolean
const volume = settingNumber(player, 'volume') // a number
player.setSetting('layout', 'full')
```

```luau
local layout = player:setting("layout") -- "full" or "compact"
local sounds = player:setting("sounds") == "true"
local volume = tonumber(player:setting("volume"))
player:setSetting("layout", "full")
```

```python
layout = player.setting("layout")  # "full" or "compact"
sounds = player.setting("sounds") == "true"
volume = float(player.setting("volume") or 0)
player.set_setting("layout", "full")
```

```go
layout, _ := p.Setting("layout") // "full" or "compact"
sounds, _ := p.SettingOn("sounds") // a switch, as a bool
volume, _ := p.SettingNumber("volume") // a number
_ = p.SetSetting("layout", "full")
```

</Samples>

A player may change a setting outside the mod, such as on a profile page.
The setting-changed event reports it:

<Samples>

```ts
import { onSettingChanged } from 'modlock'

onSettingChanged((player, key, value) => {
  if (key === 'layout') {
    player.chat(`Layout is now ${value}.`)
  }
})
```

```luau
modlock.onSettingChanged(function(player, key, value)
	if key == "layout" then
		player:chat(`Layout is now {value}.`)
	end
end)
```

```python
@modlock.on_setting_changed
def changed(player: modlock.Player, key: str, value: str) -> None:
    if key == "layout":
        player.chat(f"Layout is now {value}.")
```

```go
mod.OnSettingChanged(func(p mod.Player, key, value string) {
	if key == "layout" {
		_ = p.Chat("Layout is now " + value + ".")
	}
})
```

</Samples>

## Metrics

A metric is a running total for each player: a count, a sum or a maximum.
Declare it in [`mod.json`](/reference/manifest#metrics) and add to it. The
optional label splits one metric into several totals.

<Samples>

```ts
player.addMetric('round.wins', 1)
player.addMetric('hud.opened', 1, 'compact')
```

```luau
player:addMetric("round.wins", 1)
player:addMetric("hud.opened", 1, "compact")
```

```python
player.add_metric("round.wins", 1)
player.add_metric("hud.opened", 1, "compact")
```

```go
_ = p.AddMetric("round.wins", 1, nil)
label := "compact"
_ = p.AddMetric("hud.opened", 1, &label)
```

</Samples>

Without a host that keeps them, `modlock dev` logs a session's totals as it
ends.

## Boards

A board ranks players against each other. Declare it in
[`mod.json`](/reference/manifest#boards), then report each score with a
value for each of the board's partitions.

<Samples>

```ts
import { reportScore } from 'modlock'

reportScore(player, 'aim.score', 4210, {
  partition: { scenario: 'tracking', difficulty: 'hard' },
})
```

```go
_ = p.ReportScore(&mod.ScoreReport{
	Board:     "aim.score",
	Value:     4210,
	Partition: map[string]string{"scenario": "tracking", "difficulty": "hard"},
})
```

</Samples>

Boards report from TypeScript and Go today. `reportMatch` reports a whole
match's places to a rated board, and `readBoard` reads a page of a board,
such as its top five, to show in the game.
