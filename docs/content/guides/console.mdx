---
title: Console
description: Set console variables and run commands, within limits.
---

`modlock/console` sets console variables, each typed as the game declares it,
and runs commands:

<Samples>

```ts
import { run, set } from 'modlock/console'

set('citadel_allow_purchasing_anywhere', true)
set('citadel_trooper_gold_reward', 40)
run('changelevel', 'street_test')
```

```luau
local console = require("@modlock/console")

console.setBoolean("citadel_allow_purchasing_anywhere", true)
console.setNumber("citadel_trooper_gold_reward", 40)
console.run("changelevel", "street_test")
```

```python
from modlock import console

console.set_boolean("citadel_allow_purchasing_anywhere", True)
console.set_number("citadel_trooper_gold_reward", 40)
console.run("changelevel", "street_test")
```

```go
import "github.com/paralin/modlock/mod/console"

_ = console.CitadelAllowPurchasingAnywhere.Set(true)
_ = console.CitadelTrooperGoldReward.Set(40)
_ = console.Changelevel.Run("street_test")
```

</Samples>

Each call runs one line through `serverCommand`, which may set a
development-only or cheat-protected variable. A variable whose value is a
vector or a color has no typed setter; set it with `serverCommand`.

## Set up a mode

`apply(settings)` sets several variables in order and returns the names the
server refused. `arena` empties the map for a custom mode: the server keeps
running with no one connected, and no troopers, neutrals, practice bots or
zipline starts appear. Spread it and add the mode's own:

<Samples>

```ts
import { apply, arena } from 'modlock/console'

apply({ ...arena, citadel_allow_duplicate_heroes: true })
```

```python
from modlock import console

console.apply({**console.ARENA, "citadel_allow_duplicate_heroes": True})
```

</Samples>

## Limits

A mod's console lines change the game and nothing around it. They may set the
game's rules and bots, change or reload the map, kick a player, quit, set the
time scale, and start the game's own recording with `tv_enable` and
`tv_record <name>`, where the name holds only letters, digits, `-` and `_`.
They may not reach the engine's controls for:

- files: `exec` and its kin, saves, demo playback, config and path variables,
  and commands that write a file, such as `condump` or `writeip`;
- logging: `log`, `log_*`, `con_log*`, `sv_log*` and console redirection;
- the network: `connect`, `rcon*`, addresses and ports, IP bans, passwords,
  Steam account and group settings, and broadcast, relay and playcast `tv_*`
  settings;
- the process: crash and minidump commands, debuggers, tools and shutdown;
- commands that store a line to run later: `alias`, `cmd`, `bind*`, `unbind*`
  and `execute_command_every_frame`, and the test script's `test_*`
  commands, which run the commands they name;
- entities, past the checks of a mod's own calls: `ent_create`, `ent_fire*`,
  `ent_call` and `firetarget`, and `give` for a class
  [`createEntity` refuses](/guides/entities#create-entities-and-send-inputs);
- the script VM: `script_*`.

`toggle`, `incrementvar` and `multvar` set the variable they name, so each is
refused for a variable that may not be set directly. The server checks every
command in a line, after each `;` or newline, and returns an error that names
the first one refused.
