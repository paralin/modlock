Each call on this page places something in the world, such as text, a model, an
effect or fog. It returns an object that you can move, change or remove later.
Loading a new map, stopping the mod or reloading it removes every object the
mod placed.

## Place text

<Samples>

```ts
import { createText } from 'modlock'

const label = createText({
  text: 'START',
  position: { x: 0, y: 0, z: 200 },
  fontSize: 96,
  faceCamera: true,
})
label?.setText('GO!')
label?.move({ x: 0, y: 0, z: 260 })
label?.remove()
```

```luau
local label = modlock.createText({
	text = "START",
	position = { x = 0, y = 0, z = 200 },
	fontSize = 96,
	faceCamera = true,
})
if label then
	label:setText("GO!")
	label:move({ x = 0, y = 0, z = 260 })
	label:remove()
end
```

```python
label = modlock.create_text(
    modlock.TextOptions(
        text="START",
        position=modlock.Vector(0, 0, 200),
        font_size=96,
        face_camera=True,
    )
)
if label is not None:
    label.set_text("GO!")
    label.move(modlock.Vector(0, 0, 260))
    label.remove()
```

```go
size, faceCamera := float32(96), true
label, err := mod.CreateText(&mod.TextOptions{
	Text:       "START",
	Position:   &mod.Vector{Z: 200},
	FontSize:   &size,
	FaceCamera: &faceCamera,
})
if err == nil {
	_ = label.SetText("GO!")
	_ = label.Move(&mod.Vector{Z: 260}, nil)
	_ = label.Remove()
}
```

</Samples>

## Load heroes and resources

When your mod starts, precache the heroes, models and effects your mode uses.
The game loads them with the next world. A model or effect that the game has
not loaded shows nothing the first time your mod uses it.

<Samples>

```ts
import { onStart, precache } from 'modlock'

onStart(() => {
  precache({ heroes: ['hero_atlas', 'hero_haze'] })
})
```

```luau
modlock.onStart(function()
	modlock.precache({ heroes = { "hero_atlas", "hero_haze" } })
end)
```

```python
@modlock.on_start
def load(args: list[str]) -> None:
    modlock.precache(modlock.PrecacheOptions(heroes=["hero_atlas", "hero_haze"]))
```

```go
mod.OnStart(func([]string) {
	_ = mod.Precache(&mod.PrecacheOptions{Heroes: []string{"hero_atlas", "hero_haze"}})
})
```

</Samples>

## Forget objects when the world changes

By the time a new world loads, the game has already removed everything your mod
placed. So in your world event handler, drop your references to the old objects
and place them again.

## Hide a cue from chosen players

`hideCues(rules)` keeps a particle or sound that the server starts from the
players you name. The event that started the cue still resolves as usual. A
rule names one sound by its event name, or one particle by the 64-bit name the
game sends when it creates the particle. A rule may also name the entity the
cue plays on, and the player slots that do not get the cue. Leave the viewers
out to hide the cue from everyone. Each call replaces all of the mod's rules,
and an empty call shows every cue again.

```ts
import { hideCues } from 'modlock'

// The parrier's opponents neither see nor hear the parry.
hideCues([
  { sound: 'player.melee.parry.shared', source: parrier, viewers: [1] },
  { particleId: 0xea4556457abca994n, source: parrier, viewers: [1] },
])
```

A particle hidden from a player stays hidden from them until the game
releases the particle. The player's own client predicts some cues, such as the
parry they press themselves. Those cues never come from the server, so
no rule reaches them.
Luau takes a particle name as a decimal string, because a Luau number cannot
hold every 64-bit value.

## Every call

Python spells each call in `snake_case`, and Go capitalizes it. `Dropper`
exists only in TypeScript. TypeScript imports `loadSpot` and `Dropper` from
`modlock/kit`, and the rest from `modlock`.

| Call                                                   | Effect                                                                                                |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `createText`, `createModel`, `createParticle`          | Place text, a model or an effect to move, change or remove later.                                     |
| `createFog({ position, mins, maxs, strength, color })` | Fill a box with tinted fog. Tile boxes to darken all but one area.                                    |
| `precache({ heroes, resources })`                      | Load heroes and resources with the next world.                                                        |
| `serverCommand(line)`                                  | Run a line at the server console, within [its limits](/guides/console#limits).                        |
| `moveEntity`                                           | Move an entity.                                                                                       |
| `pushEntity`                                           | Set or add to an entity's velocity.                                                                   |
| `emitSound`                                            | Play a sound on an entity.                                                                            |
| `modifierState(entity, state)`, `holdModifierState`    | Test or hold a modifier state on an entity.                                                           |
| `silenceVoice(concepts)`, `player.silenceVoice`        | Keep every hero, or one, from speaking the listed voice concepts.                                     |
| `hideCues(rules)`                                      | Keep chosen particles and sounds from chosen players; see [above](#hide-a-cue-from-chosen-players).   |
| `giveEntityModifier`, `holdEntityModifier`             | Give or hold a modifier on a live entity, such as an NPC.                                             |
| `readField`, `writeField`, `entityClass`               | Read or write any schema field of a live entity, or read its class; see [Entities](/guides/entities). |
| `loadSpot(spot)`                                       | Place a [spot](/guides/world#spots) on the running map.                                               |
| `encodeSpot`, `decodeSpot`                             | Save a spot, or restore a saved one.                                                                  |
| `new Dropper(catalog, spot)`                           | Let players build a spot while they play.                                                             |

## Spots

A spot is a base map plus the solid objects players placed on it.
[`examples/dropper`](https://github.com/paralin/modlock/tree/master/examples/dropper) builds a
spot on Midtown. `/build` opens the catalog of objects, and every player drops
into the same spot. The document at
[`mod/spot/spot.proto`](https://github.com/paralin/modlock/blob/master/mod/spot/spot.proto)
stores a spot with each model path and builder written once, so a few hundred
objects fit in a few kilobytes.
