A mod places things in the world: text, models, effects and fog. Each is an
object you move, change or remove later. A new map removes them all, and so
does stopping or reloading the mod.

## Place text

<Samples>

```ts
import { createText } from 'modlock'

const label = createText({
  text: 'START',
  position: { x: 0, y: 0, z: 200 },
  fontSize: 96,
  faceCamera: true,
})
label?.setText('GO!')
label?.move({ x: 0, y: 0, z: 260 })
label?.remove()
```

```luau
local label = modlock.createText({
	text = "START",
	position = { x = 0, y = 0, z = 200 },
	fontSize = 96,
	faceCamera = true,
})
if label then
	label:setText("GO!")
	label:move({ x = 0, y = 0, z = 260 })
	label:remove()
end
```

```python
label = modlock.create_text(
    modlock.TextOptions(
        text="START",
        position=modlock.Vector(0, 0, 200),
        font_size=96,
        face_camera=True,
    )
)
if label is not None:
    label.set_text("GO!")
    label.move(modlock.Vector(0, 0, 260))
    label.remove()
```

```go
size, faceCamera := float32(96), true
label, err := mod.CreateText(&mod.TextOptions{
	Text:       "START",
	Position:   &mod.Vector{Z: 200},
	FontSize:   &size,
	FaceCamera: &faceCamera,
})
if err == nil {
	_ = label.SetText("GO!")
	_ = label.Move(&mod.Vector{Z: 260}, nil)
	_ = label.Remove()
}
```

</Samples>

## Load heroes and resources

The game loads a hero, model or effect with the world. Precache what your
mode uses when the mod starts, or the first use shows nothing.

<Samples>

```ts
import { onStart, precache } from 'modlock'

onStart(() => {
  precache({ heroes: ['hero_atlas', 'hero_haze'] })
})
```

```luau
modlock.onStart(function()
	modlock.precache({ heroes = { "hero_atlas", "hero_haze" } })
end)
```

```python
@modlock.on_start
def load(args: list[str]) -> None:
    modlock.precache(modlock.PrecacheOptions(heroes=["hero_atlas", "hero_haze"]))
```

```go
mod.OnStart(func([]string) {
	_ = mod.Precache(&mod.PrecacheOptions{Heroes: []string{"hero_atlas", "hero_haze"}})
})
```

</Samples>

## Forget objects when the world changes

A new world has already removed everything the mod placed. Drop your
references in the world event and place things again there.

## Every call

The table names each call as TypeScript and Luau spell it; Python uses
snake_case and Go exported names. `Dropper` is part of the TypeScript
library today.

| Call                                                     | Effect                                                                         |
| -------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `createText`, `createModel`, `createParticle`            | Place text, a model or an effect; move, change or remove it later.             |
| `createFog({ position, mins, maxs, strength, color })`   | Fill a box with tinted fog; tile boxes to darken all but one area.             |
| `precache({ heroes, resources })`                        | Load heroes and resources with the next world.                                 |
| `serverCommand(line)`                                    | Run a line at the server console, within [its limits](/guides/console#limits). |
| `moveEntity`, `pushEntity`, `emitSound`                  | Move an entity, set or add to its velocity, or play a sound on it.             |
| `modifierState(entity, state)`, `holdModifierState(...)` | Test a modifier state on an entity, or hold one on it.                         |
| `silenceVoice(concepts)`, `player.silenceVoice(...)`     | Keep every hero, or one, from speaking the named voice concepts.               |
| `giveEntityModifier`, `holdEntityModifier`               | Give a modifier to a live entity, such as an NPC, or hold it on it.            |
| `readField`, `writeField`, `entityClass`                 | Read or write any schema field of a live entity, or name its class.            |
| `loadSpot(spot)`, `encodeSpot`, `decodeSpot`             | Place a [spot](/guides/world#spots) on the running map, or save it.            |
| `new Dropper(catalog, spot)`                             | Let players build a spot while they play.                                      |

## Spots

A spot is a base map and the solid objects players placed on it.
[`examples/dropper`](https://github.com/paralin/modlock/tree/master/examples/dropper) builds one on Midtown: `/build` opens the
catalog, and every player drops into the same spot. The document in
[`mod/spot/spot.proto`](https://github.com/paralin/modlock/blob/master/mod/spot/spot.proto) stores each
model path and builder once, so a few hundred objects fit in a few kilobytes.
