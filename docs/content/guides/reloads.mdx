---
title: Reloads and failures
description: What a reload resets, how to carry state across one, and what a failed call does.
---

`modlock dev` swaps in a new build each time you save while the game runs. A reload starts the mod fresh: its variables reset, and everything it placed is removed.

## Failed calls

A failed call logs the reason and returns `false` or `undefined`. The mod keeps running. Everything a mod places leaves with the world. Stopping or reloading the mod removes it and releases frozen heroes, modifier states and input.

<Only lang="go">
  In Go each call returns an error instead. A mod may ignore the error to keep
  playing.
</Only>

## Slow and stopped mods

Processor time counts the game calls an event makes, but not a stall where the
server waits, such as paging on a machine short of memory.

| An event that                      | Does                                                                                                                                                   |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| runs past 500 ms of processor time | Still finishes. The host logs where its time went, warns the players in chat, and for five minutes lets any player restart the mod with `/restartmod`. |
| runs past five seconds             | Stops the mod, as a crash does.                                                                                                                        |

A stopped mod clears what it placed and shows and stays stopped. The host warns
in chat each minute until a player types `/restartmod` or a reload replaces it.
A restart starts the same build in a new instance, as a reload does.

## Hold a reload

When a new build would lose work in progress, such as a timed run, call `holdReload(true)` at the start and `holdReload(false)` when it ends. A reload that arrives meanwhile waits. The newest build replaces the running one on the next frame after the release. A mod that stops also releases its hold.

<Samples>

```ts
import { holdReload } from 'modlock'

function startRun() {
  holdReload(true)
}

function endRun() {
  holdReload(false)
}
```

```luau
local function startRun()
	modlock.holdReload(true)
end

local function endRun()
	modlock.holdReload(false)
end
```

```python
def start_run() -> None:
    modlock.hold_reload(True)


def end_run() -> None:
    modlock.hold_reload(False)
```

```go
func startRun() { _ = mod.HoldReload(true) }

func endRun() { _ = mod.HoldReload(false) }
```

</Samples>

## Hand state to the next build

Handoff state carries what a reload should not reset, such as which round it plays or the panels each player has open, to the next build.

`handoff(text)` writes the game's handoff state.
`player.handoff(text)` writes one player's handoff state.
`handedOff()` reads the game's handoff state on load.
`player.handedOff()` reads a player's handoff state on load.

Handoff state lasts only through a reload in the same game. The host holds it in memory only, up to 64 KiB per call. The game's handoff state ends when the mod stops or the server restarts. A player's handoff state ends when that player leaves. A bot has no handoff state. Handing off an empty text forgets it.

<Samples>

```ts
import { handedOff, handoff } from 'modlock'

// Pick up the round the last build was on.
let round = Number(handedOff() ?? 1)

function nextRound() {
  round += 1
  handoff(String(round))
}
```

```luau
-- Pick up the round the last build was on.
local round = tonumber(modlock.handedOff()) or 1

local function nextRound()
	round += 1
	modlock.handoff(tostring(round))
end
```

```python
# Pick up the round the last build was on.
round_number = int(modlock.handed_off() or 1)


def next_round() -> None:
    global round_number
    round_number += 1
    modlock.handoff(str(round_number))
```

```go
var round = 1

func init() {
	// Pick up the round the last build was on.
	mod.OnStart(func([]string) {
		if text, err := mod.HandedOff(); err == nil {
			if n, err := strconv.Atoi(text); err == nil {
				round = n
			}
		}
	})
}

func nextRound() {
	round++
	_ = mod.Handoff(strconv.Itoa(round))
}
```

</Samples>
