title: Your first mod

---

With `modlock` installed, you can create a project, run it in Deadlock, and
hot-reload changes while playing.

## Create a project

Run these commands in a terminal:

```sh
modlock new
cd my-mod
modlock dev
```

`modlock new` prompts for your mod's name and language, then creates a project
directory named after the slug (for example, "Zombie Tag" becomes `zombie-tag`).

## Project files

A project directory contains the manifest, an entry file, and the language-specific
configuration your editor uses:

| Language   | Files                                                    | Notes                                                   |
| ---------- | -------------------------------------------------------- | ------------------------------------------------------- |
| TypeScript | `mod.json`, `main.ts`, `tsconfig.json`, `node_modules/`  | `node_modules/modlock` provides the type definitions.   |
| JavaScript | `mod.json`, `main.js`, `tsconfig.json`, `node_modules/`  | Your editor checks types from JSDoc comments.           |
| Luau       | `mod.json`, `main.luau`, `.luaurc`, `.modlock/`          | `.modlock/` provides the type definitions.              |
| Python     | `mod.json`, `main.py`, `pyrightconfig.json`, `.modlock/` | `.modlock/` provides the type definitions.              |
| Go         | `mod.json`, `main.go`, `go.mod`, `go.sum`                | `modlock new` requires [Go](https://go.dev/dl/).        |

Every project also includes a `.gitignore` and `.vscode/extensions.json` with
recommended editor extensions for its language.

`mod.json` is the [manifest](/reference/manifest), which defines the mod's slug,
name, and version. The entry file (such as `main.ts`) holds your mod's code.
`modlock new` generates a starter template that disables lane troopers and
jungle creeps, allows duplicate hero picks, [seats](/guides/toolkit#seat-the-players)
joining players on a team with a hero, and respawns fallen heroes after 3
seconds. It also welcomes each player and responds to `/hello` in chat. Remove
anything your mode does not need.

## Run it

`modlock dev` builds your mod, starts a local server, and launches Deadlock
through Steam to connect. The terminal streams your mod's logs while it runs.

Type `/hello` in the game chat, then edit the reply in the entry file and save.
`modlock dev` rebuilds and hot-reloads the mod in the running server on every
save, so typing `/hello` again shows your updated reply. If a build fails,
`modlock dev` prints the errors and the server keeps running the last working
build.

On systems without Deadlock (such as macOS), `modlock dev` runs your mod in the
[sandbox](/guides/testing#in-the-sandbox) instead, where you can type `/hello`
directly in the terminal.

## Troubleshooting

| Symptom                                                  | Fix                                                                                                                 |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `modlock` is not recognized                              | See [Install](/start/install).                                                                                      |
| `Import "modlock" could not be resolved` in a Python mod | Open the mod's own folder in your editor. Pyright reads `pyrightconfig.json` only from the workspace root.          |
| `modlock new` exits before creating a Go project         | Install [Go](https://go.dev/dl/), then run `modlock new` again.                                                     |
