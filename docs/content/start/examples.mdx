---
title: Examples
description: Complete mods to read, run and start from.
---

Every example is a whole project in the repository's
[`examples`](https://github.com/paralin/modlock/tree/master/examples)
directory. Clone the repository and run one with `modlock dev` from its
directory.

| Example                                                                                | Shows                                                               |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| [`hello-ts`](https://github.com/paralin/modlock/tree/master/examples/hello-ts)         | Commands, a JSX menu with buttons, moving text, a setting, metrics. |
| [`arena`](https://github.com/paralin/modlock/tree/master/examples/arena)               | A free-for-all: ready-up, countdown, kills, bots, a self-test.      |
| [`hill`](https://github.com/paralin/modlock/tree/master/examples/hill)                 | King of the hill: a ring of world text, team scores, progress bars. |
| [`drill`](https://github.com/paralin/modlock/tree/master/examples/drill)               | An aim drill: target bots, headshots, a length setting, best score. |
| [`dropper`](https://github.com/paralin/modlock/tree/master/examples/dropper)           | Building a spot of solid objects while playing.                     |
| [`world-panel`](https://github.com/paralin/modlock/tree/master/examples/world-panel)   | A board of the mod's own layout, drawn in the world.                |
| [`inventory`](https://github.com/paralin/modlock/tree/master/examples/inventory)       | A drag inventory in the mod's own layout, script and style sheet.   |
| [`bounty`](https://github.com/paralin/modlock/tree/master/examples/bounty)             | A Luau free-for-all: a bounty marker, damage hooks, flares, bots.   |
| [`race`](https://github.com/paralin/modlock/tree/master/examples/race)                 | A Go checkpoint race: a marked course, laps, resets, unit tests.    |
| [`hello-luau`](https://github.com/paralin/modlock/tree/master/examples/hello-luau)     | The smallest mod in Luau.                                           |
| [`hello-python`](https://github.com/paralin/modlock/tree/master/examples/hello-python) | The smallest mod in Python.                                         |
| [`hello-go`](https://github.com/paralin/modlock/tree/master/examples/hello-go)         | The smallest mod in Go.                                             |
| [`hello`](https://github.com/paralin/modlock/tree/master/examples/hello)               | A native C++ plugin.                                                |

The same small mod in each language, for comparing them side by side:
