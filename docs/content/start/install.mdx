---
title: Install
description: Install the modlock command.
---

Install `modlock` with the line for your computer.

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/paralin/modlock/master/install.ps1 | iex
```

macOS or Linux, in a terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/paralin/modlock/master/install.sh | sh
```

Or with npm, into a project:

```sh
npm install --save-dev @modlock/modlock
npx modlock new my-mod
```

With npm, run every command through `npx`, as in `npx modlock dev`.

That is all a TypeScript, JavaScript, Luau or Python mod needs. A Go mod also
needs [Go](https://go.dev/dl/). On its first run, `modlock` downloads the game
server, and `modlock update` installs a newer release.

<Callout title="modlock is not found">
  On Windows, a program already running keeps the old `PATH`. Close the terminal
  and open it again. For a terminal inside VS Code, close the whole editor. On
  macOS or Linux, the installer prints a line to add to your shell's startup
  file when its directory is not on your `PATH`.
</Callout>

## Download it by hand

Download the file for your computer from the
[latest release](https://github.com/paralin/modlock/releases/latest), rename it
to `modlock` (`modlock.exe` on Windows), and put it in a directory on your
`PATH`. On macOS or Linux, make it runnable with `chmod +x modlock`.

| Your computer               | File                        |
| --------------------------- | --------------------------- |
| Windows                     | `modlock-windows-amd64.exe` |
| Mac with Apple silicon      | `modlock-darwin-arm64`      |
| Mac with an Intel processor | `modlock-darwin-amd64`      |
| Linux, x86-64               | `modlock-linux-amd64`       |
| Linux, ARM64                | `modlock-linux-arm64`       |

A file downloaded in a browser can trigger a Windows SmartScreen or macOS
warning; the installers avoid this. On a Mac, clear it with
`xattr -c modlock`. `modlock` is a terminal program, so run it from
a terminal. Double-clicking it only prints how to install it.

To run Modlock from a clone, see
[Building Modlock](/internals/building#run-the-command-from-a-clone).
