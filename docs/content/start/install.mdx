---
title: Install
description: Install the modlock command.
---

Install the `modlock` command by running the line for your computer.

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/paralin/modlock/master/install.ps1 | iex
```

macOS or Linux, in a terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/paralin/modlock/master/install.sh | sh
```

Or with npm, into a project:

```sh
npm install --save-dev @modlock/modlock
npx modlock new my-mod
```

When you install with npm, run every command through `npx`, as in
`npx modlock dev`.

That is all you need for TypeScript, JavaScript, Luau, or Python. Go mods also
require [Go](https://go.dev/dl/). On its first run, `modlock` downloads the
game server. Run `modlock update` to upgrade later.

<Callout title="modlock is not found">
  On Windows, an already-open terminal keeps its initial `PATH`. Close it and
  open a new one (or restart VS Code if using its integrated terminal). On
  macOS or Linux, if the install directory is not on your `PATH`, the installer
  prints the line to add to your shell profile.
</Callout>

Next: [make your first mod](/start/first-mod).

## Manual download

Download the binary for your platform from the
[latest release](https://github.com/paralin/modlock/releases/latest), rename it
to `modlock` (`modlock.exe` on Windows), and place it in a directory on your
`PATH`. On macOS or Linux, make it executable with `chmod +x modlock`.

| Platform                    | Binary                      |
| --------------------------- | --------------------------- |
| Windows                     | `modlock-windows-amd64.exe` |
| macOS (Apple silicon)       | `modlock-darwin-arm64`      |
| macOS (Intel)               | `modlock-darwin-amd64`      |
| Linux, x86-64               | `modlock-linux-amd64`       |
| Linux, ARM64                | `modlock-linux-arm64`       |

Windows SmartScreen and macOS Gatekeeper warn on binaries downloaded through a
browser. The install commands above bypass browser quarantine, so they do not
trigger that warning. On macOS, clear the quarantine attribute with
`xattr -c modlock`. Run `modlock` from a terminal; double-clicking it only
prints installation instructions.

To run Modlock from a source clone, see
[Building Modlock](/internals/building#run-the-command-from-a-clone).
