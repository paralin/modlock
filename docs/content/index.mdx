<Hero />

Modlock gives each language a library with the same events and calls, so you
can write your mod in the language you already know. This mod replies when a
player types `/hello` in chat:

<Samples>

```ts
import { command } from 'modlock'

command('hello', (player) => {
  player.chat('Hello from TypeScript!')
})
```

```luau
local modlock = require("@modlock")

modlock.command("hello", function(player)
	player:chat("Hello from Luau!")
end)
```

```python
import modlock


@modlock.command("hello")
def hello(player: modlock.Player, args: str) -> None:
    player.chat("Hello from Python!")
```

```go
package main

import "github.com/paralin/modlock/mod"

func init() {
	mod.Command("hello", func(p mod.Player, args string) {
		_ = p.Chat("Hello from Go!")
	})
}

func main() {}
```

</Samples>

<Callout title="Early development">
  You can write, run and publish mods in TypeScript, JavaScript, Luau, Python
  and Go in the current release, but the library may still change between
  releases.
</Callout>

## Why WebAssembly

<Cards>
  <Card icon={<ShieldCheck />} title="Safe to share">
    Each mod runs in a [Wasmtime] sandbox with access only to its own files and
    no network access. If a mod crashes or hangs, the server halts that mod and
    the match continues.
  </Card>
  <Card icon={<Languages />} title="Any language">
    Write a mod in any language that compiles to WebAssembly.
  </Card>
  <Card icon={<Package />} title="Built once">
    The server resolves each game field and input by name rather than offset, so
    a mod compiled before a game update continues to work after the update.
  </Card>
  <Card icon={<Zap />} title="Fast">
    Wasmtime compiles the mod's WebAssembly to machine code ahead of time, and
    the server invokes it directly inside the game frame.
  </Card>
</Cards>

[Wasmtime]: https://wasmtime.dev
